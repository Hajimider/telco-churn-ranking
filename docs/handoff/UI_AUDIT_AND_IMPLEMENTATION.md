## 设计规范

- 颜色：延用 canvas `#F5F1EB`、surface `#FFFDF9`、sidebar `#FBF8F3`、heading `#243B3A`、ink `#263238`、muted `#596560`、line `#DED6CB`、teal `#176B63`。风险等级继续用现有红/棕/绿及明确文字。
- 模型颜色与既有校准图一致：逻辑回归 `#006B40`、随机森林 `#BF754E`、LightGBM `#2465AD`；ROC 额外用实/虚/点划线。策略图同名模型保持模型色，经验规则和随机基线用中性色，不能用颜色宣称主模型赢过其他模型。
- 字体：标题保留 Noto Serif SC / Source Han Serif SC / Microsoft YaHei 的现有回退；正文明确 Microsoft YaHei / PingFang SC / Noto Sans SC / system-ui；指标用同一无衬线并启用表格数字。无远程字体请求。
- 层级：页标题 32–38px、二级标题 20–24px、正文 14–16px、辅助信息 13px；手机标题 26–28px。减少 KPI 内部冗余留白。
- 间距：8px 基础节奏，卡片 16–20px 内边距、区域 24–32px；圆角 10–12px；阴影只用于指标、避免全页浮起。
- 布局：桌面最大宽 1440px，侧栏保留原生收起；四 KPI 等分，手机两列；主要证据优先，长表限定高度并局部滚动。
- 交互：44px 左右触控目标；保留原控件标签、选择范围、默认值、会话缓存和报告切换；键盘焦点可见，低动态偏好关闭过渡。
- 不新增时间趋势、在线/实时状态、虚构增长率、阈值优化控件、触达成功率或生产级宣称。

## 交给 Codex 的可执行任务

按以下顺序执行，仅需渐进编辑现有文件：

1. `dashboard.py / inject_styles`：统一设计令牌；保留暖白青绿；优化正文、导航、选中、焦点、按钮与响应式 KPI；保留运行反馈。`.streamlit/config.toml` 用原生主题选项统一表头、边框和语义颜色。
2. `dashboard.py / render_table`：保留 HTML 小表、增强数值对齐/千位符/空值；长表使用原生 dataframe，格式仅作用于显示，不能把底层比例乘100后导出，不能截断掉原有行列。保持 HTML 转义。
3. `dashboard.py / _base_figure 与 render_*`：统一背景/文字/网格；同名模型固定配色、保留直接标签和误差口径；混淆矩阵独立可折行，不改输入、分类阈值或数值。
4. `dashboard.py / 六页布局`：总览复用 policy 数据主图；分群与 CV 主图先于明细；主要图表使用原生有边框容器；AI 维持原始请求与缓存，仅优化视觉分组与行动按钮。
5. `scripts/capture_demo.py`：修复报告选择确认；增加独立输出目录、390px 截图，等待末尾内容、图片、字体完成，截图禁止自动点击生成 AI。
6. 验证：先做 AppTest 定向检查，再运行现有全套 pytest；启动真实 run_final 页面测试六页、分群/策略/客户/SHAP选择、报告切换、返回保持、离线模板；检查 1440/1024/390/320px、局部滚动、焦点和无页面横向溢出。保留修改前后六页截图与手机图，不覆盖旧作品集图。
7. 独立审查展示层 diff，确认模型/SQL/接口/outputs 未改，补充本文件实际验收结果。PyCharm 使用现有项目解释器，以模块 streamlit、参数 `run dashboard.py -- --output outputs/run_final`、工作目录仓库根目录运行；终端见 `docs/RUNNING.md`。
