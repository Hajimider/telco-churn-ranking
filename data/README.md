# 数据准备

从 [Kaggle Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) 下载 `WA_Fn-UseC_-Telco-Customer-Churn.csv`，保留原始文件名并放在本目录。原始 CSV 不纳入版本控制。

在项目根目录运行：

```bash
python run_project.py --data data/WA_Fn-UseC_-Telco-Customer-Churn.csv --output outputs/project_v1
```

输出目录必须不存在或为空。完整运行步骤和字段要求见[项目 README](../README.md)。
